# Daily Yoo! · 项目展示

**给每天一个更清楚的安排。**

Daily Yoo! 是一款正在开发的 Android 本地优先日程、任务、个人记忆与复盘助手。它希望让日常安排更容易看清，也让 AI 的建议始终由用户决定是否执行。

🌐 [查看项目展示页](https://nalongur.github.io/Dailyoo-showcase/)

## 产品方向

- **日程与任务**：在同一个地方整理安排，并查看时间冲突与忙碌情况。
- **可确认的 AI 建议**：对话可以提出任务或日程调整方案；修改数据前需要用户确认。
- **个人记忆与复盘**：记录有来源、可编辑的个人记忆，并基于真实活动回看一段时间。
- **本地优先**：应用数据默认保存在设备；AI 请求只发送完成请求所需、且允许发送的上下文到用户配置的服务。

以上是产品方向，**不代表所有功能已完成或通过设备验收**。目前项目处于开发阶段，暂无公开安装包。界面和功能会继续调整。

## 隐私边界

Daily Yoo! 的 MVP 不要求应用账号，也不提供云同步。使用 AI 功能时，请求会发往用户自行配置的第三方 API；“本地优先”不意味着 AI 数据完全不离开设备。系统日历自身是否同步，由手机上的日历账户决定。
